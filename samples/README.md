# サンプル定義フォルダ

ここに「この入力→この出力」のサンプルセットを置くことで、議事録生成のルールを定義します。

## フォルダ構成

```
samples/
├── 001/                     # サンプルセット番号
│   ├── input/
│   │   ├── audio.mp3        # 音声データ（MP3 or M4A）
│   │   └── schedule.pdf     # 会議日程・内容PDF
│   ├── expected_output/
│   │   └── minutes.docx     # 期待する議事録Word
│   └── README.md            # このサンプルの説明
├── 002/
│   └── ...
└── README.md                # このファイル
```

## サンプルの追加方法

1. `samples/` 以下に連番フォルダを作成（例：`003/`）
2. `input/` に音声（MP3/M4A）と日程PDF を置く
3. `expected_output/` に完成形の Word ファイルを置く
4. `README.md` に会議名・日付・特記事項を書く

サンプルが多いほど、生成ルールの精度が上がります。
